# PR 2 – Sales Data Analyzer

## Project Overview

This project is an Excel-based Sales Data Analysis project.

The main purpose of this project is to analyze sales, profit, customers, products, regions, and monthly performance using Excel.

## Dataset

The dataset contains 200 sales transaction records with information such as:

* Order Date
* Customer ID
* Customer Name
* Product
* Region
* Sales
* Cost
* Profit
* Discount

## Analysis Performed

The following analysis was completed in Excel:

1. **Sales and Profit Analysis**

   * Total Sales
   * Total Cost
   * Total Profit
   * Average Sales
   * Average Profit

2. **Monthly Sales Analysis**

   * Monthly sales totals
   * Monthly growth
   * Increase/decrease indicators

3. **Customer Analysis**

   * Customer-wise sales
   * Top 10 customers
   * Customer ranking

4. **Product and Region Analysis**

   * Sales by product
   * Sales by region
   * Region vs Product analysis

5. **Descriptive Statistics**

   * Mean
   * Median
   * Standard Deviation
   * Minimum
   * Maximum
   * Other basic statistics

6. **Regression Analysis**

   * Relationship between Sales and Profit
   * R-squared value
   * Regression coefficients
   * Regression equation

7. **What-If Analysis**

   * Different discount scenarios
   * Estimated effect on sales and profit

8. **Charts and Visualization**

   * Sales trend chart
   * Product/region comparison chart
   * Sales distribution chart
   * Profit vs Sales chart

Through this project, I learned how to clean and analyze sales data in Excel, use formulas for calculations, create charts, perform basic statistical analysis, and understand relationships between different variables.
